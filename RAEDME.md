# 🧠 Quiz Application

A simple command-line quiz application featuring multiple-choice questions, instant feedback, automatic scoring, and performance evaluation.

## Features

- Multiple-choice questions
- Randomized question order
- Instant answer feedback
- Input validation
- Automatic score calculation
- Final percentage and performance rating
- Option to replay the quiz

## Technologies Used

- Python 3
- Lists and dictionaries
- Functions
- Loops and conditional statements
- Random module

## Getting Started

### Prerequisites

Python 3 must be installed.

### Run the Application

Clone the repository:

```bash
git clone https://github.com/Shivamtripathi78/quiz-application.git
```

Navigate to the project directory:

```bash
cd quiz-application
```

Run the program:

```bash
python main.py
```

## How to Play

1. Select Start Quiz.
2. Answer each question using A, B, C, or D.
3. Receive feedback after every answer.
4. View your final score and performance.
5. Replay or exit.
